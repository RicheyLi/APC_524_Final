# Installation

## Stable release

To install Wildfire Spread and Suppression Model, run this command in your terminal:

```sh
uv add Wildfire-Spread-and-Suppression-Model
```

Or if you prefer to use `pip`:

```sh
pip install Wildfire-Spread-and-Suppression-Model
```

## From source

The source files for Wildfire Spread and Suppression Model can be downloaded from the [Github repo](https://github.com/rl3936/Wildfire-Spread-and-Suppression-Model).

You can either clone the public repository:

```sh
git clone https://github.com/rl3936/Wildfire-Spread-and-Suppression-Model
```

Or download the [tarball](https://github.com/rl3936/Wildfire-Spread-and-Suppression-Model/tarball/main):

```sh
curl -OJL https://github.com/rl3936/Wildfire-Spread-and-Suppression-Model/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd Wildfire-Spread-and-Suppression-Model
uv sync
```
